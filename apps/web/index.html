Usage

使用边界

本地服务Ollama 和 LM Studio 通常无需填写密钥，但需要允许当前网页跨域访问本机接口。
远程服务题库文本会发送到所填写的远程接口。纯前端页面无法绝对保护云端密钥，建议使用自己的代理服务。
人工核对AI 整理、核对和补解析都只生成预览或建议，不会自动写入题库，也不会绕过确认导入。

设置与导出

定期导出备份，避免本地数据丢失设置页只导出完整数据备份；单个题库或选中题库 JSON 请到题库管理页导出。

数据保存在浏览器 localStorage 中。更换浏览器或清理缓存会丢失数据，请定期导出。Web 完整备份适合 Web 端恢复；含图片备份 ZIP 可保留图片及现有可交换学习数据，并兼容旧版备份格式。
