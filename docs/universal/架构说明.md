# 架构说明

本仓库当前维护 Web 与 Windows 桌面，采用单仓多工程；桌面复用 Web 业务，通过平台适配连接受控原生能力。

## 目录与边界

| 路径 | 职责 |
| --- | --- |
| apps/web | HTML/CSS/JavaScript 共享业务、题库解析、练习考试、错题收藏、导入导出 |
| apps/web/platform | 平台契约、校验、浏览器存储/服务和保存队列 |
| apps/desktop/frontend | 桌面适配、窗口和视觉资源 |
| apps/desktop/src-tauri | Tauri 2/Rust，SQLite、媒体、恢复点、受控文件/网络及 Windows 凭据 |
| apps/desktop/scripts | 从 Web 准备资源、验证与发布辅助脚本 |
| apps/desktop/dist | 自动生成的桌面资源，不维护第二份业务源码 |
| test/dual-platform | 当前 Web/Windows 共享与浏览器回归 |
| test/fixtures/legacy-android-parser | 旧 Kotlin 解析参考样例，没有当前构建或执行器 |
| docs/archive | 历史设计、Android 材料及旧版说明副本 |
| assets | 共享图片与设计素材 |

当前没有实施 packages/core、parser 或 types 等独立包架构；平台退出维护不引入新的框架和依赖。

## 数据和服务

Web 使用浏览器存储，桌面通过原生适配保存 SQLite/媒体并按需加载。两端来源和本机数据相互独立，使用现有 JSON/ZIP 主动交换。旧 Android 备份兼容仍由共享转换、校验和测试维护，格式名称中的 native 不代表仍有安卓工程。

Web AI/WebDAV 由浏览器请求；桌面使用受控原生业务操作与系统凭据管理器。没有开放通用 SQL、文件系统、shell 或任意 HTTP IPC，CSP 和证书校验继续保持。

当前平台限制与验收见[桌面说明](../../apps/desktop/README.md)及[共享验证记录](../../test/dual-platform/README.md)。Android 历史与迁移见[停止维护说明](Android停止维护与迁移.md)，不因保留历史备份而承诺安卓专属功能迁移。
