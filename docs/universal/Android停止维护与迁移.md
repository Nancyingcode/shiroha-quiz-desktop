# Android 停止维护与旧备份迁移

自 2026-11-05 本次源码调整起，本仓库只维护 Web 与 Windows 桌面；Android 原生版和 WebView 壳不再提供构建与维护入口。本说明不代表上游仓库停止维护，也不删除历史 APK、标签或 Git 记录。移除生效的发行版本尚未指定。

## 先备份，再迁移

1. 在仍可运行的旧应用内导出备份，保留原件；含图片优先使用 ZIP。不要先卸载或清除应用数据。
2. 打开 Web 或 Windows 桌面的“设置与导出 → 备份与恢复 → 导入备份 JSON/ZIP”。选择“合并导入”以保留当前数据，或核对确认后使用“覆盖恢复”。
3. 核对题库和题目数量、标准答案、图片、多空答案、错题、收藏及学习记录。旧 WebView 壳使用它自己已有的导出能力，不会自动读取原生版的数据。
4. 核对后导出目标端的 Web 完整 JSON；需要保留图片及兼容学习数据时可使用“导出含图片备份 ZIP”。原始安卓备份继续保留。
5. 重新配置 API Key、MinerU Token、WebDAV 密码。凭据不通过题库备份迁移。

## 兼容范围

保留当前已支持的旧 Android JSON/ZIP 格式和校验规则，包括 v3 自建样本中的图片、多空、错题、收藏与学习记录。未知未来版本明确拒绝；损坏或缺图时先保留原文件，核对提示，不将部分恢复当作完整成功。

“含图片备份 ZIP”沿用原 `shiroha_quiz_web_native_backup` 格式和版本，文件名中的 `native-backup` 也保留。它保存题库、图片及现有可交换学习数据，与 Web 完整 JSON 的载荷不同，不是所有平台设置的完整克隆。

背题、斩题、智能复习、安卓自动备份等专属功能没有因此移植。历史字段能否展示和往返以现有兼容实现为准，不承诺还原安卓全部状态。Web 与桌面各自保存本机数据，不会自动同步。

本项目没有读取 Android 私有存储、扫描手机数据或恢复无法导出的应用数据的功能。本次不清理 SDK、JDK、缓存、签名文件或已安装应用。
