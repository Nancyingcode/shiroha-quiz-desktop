# 题库导入格式支持说明

适用范围：本仓库当前维护的 Web 与 Windows 桌面，两端复用 apps/web 的解析代码。旧 Android 原生解析器的完整规则已保存在[历史说明](../archive/android-era-documents/题库导入格式支持说明/Shiroha_Quiz_题库导入格式支持说明.md)，不作为当前能力承诺。

## 文件与入口

| 文件 | 当前使用方式 |
| --- | --- |
| TXT、粘贴文本 | 导入题库页，推荐明确题号、选项、答案与解析标记 |
| DOCX | 导入题库页，核对转换后的文字、公式和题目；旧 Android 专属图片提取不构成当前承诺 |
| XLSX、CSV | 导入题库页，优先一行一题、明确题干与答案列 |
| 普通题库 JSON | 支持已有题目数组、单题库及多题库结构；按识别结果核对题库内容 |
| 文字层 PDF | 使用 PDF.js 提取文字，再识别核对 |
| 扫描 PDF | 使用 OCR 测试区，先核对识别文字再导入 |
| 题目文件与答案文件 | 使用双文件导入，核对题号匹配、题型与答案覆盖 |
| 完整备份 JSON/ZIP | 优先到设置与导出的备份恢复入口，明确选择合并或覆盖 |

旧 DOC/XLS/XLSM 建议先另存为受支持格式。图片和富内容应通过已支持的题库 JSON/ZIP 保留，并在预览中检查，不手写内部素材路径。

## 推荐文本格式

采用[标准格式示例](../标准题库格式示例/标准题库格式示例.md)：每题单独编号，选项以 A、B、C、D 明确区分，使用“答案：”“解析：”标记。支持单选、多选、判断、填空（含多空）和简答，保持原题含义，不编造缺失答案。

复杂材料、共用题干、集中答案区、紧凑排版和分区重复编号必须逐题核对。Android 历史样例的通过结果不能代替当前 Web 实测；无法可靠识别时先整理成标准格式。

## 备份兼容

保留旧 Android JSON/ZIP 的现有导入与导出兼容，包括已有 v3 样本中的图片、多空、错题、收藏与记录。未知未来版本拒绝，缺图或损坏须核对提示；不移植安卓独有学习模式。

“导出含图片备份 ZIP”沿用旧兼容格式，不等于全部设置的完整克隆。迁移步骤见[旧安卓备份迁移](../universal/Android停止维护与迁移.md)。现有题库模板与格式版本不变。
