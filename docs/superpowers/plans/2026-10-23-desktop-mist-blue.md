生成器测试先覆盖新增引用、来源保全与非法输入失败，再实现资源接入。纯 CSS 的 `frontend` 目录暴露了既有平台 lint 的空 glob 问题：先增加失败回归，再改成只枚举实际 JavaScript 文件；嵌套违规脚本仍能被检查，不放宽 lint 规则。

视觉检查修正了历史高优先级规则造成的窄窗口横排菜单、顶栏挤压和首页滤镜白底，保留危险按钮的红色语义，并为宽屏固定统计栏预留题目卡宽度。最终截图等待有限动画结束，避免将过渡中的透明或位移误作最终布局。

首轮专注测试错误地要求手动收起后自动展开；按已有状态约定修正测试，分别验证练习中手动选择的收起状态保留、考试中未手动切换时退出后自动恢复，不改变业务状态逻辑。最终按钮遮挡检查覆盖横向三个位置。

实际桌面验证还包括界面导入隔离题库、关闭重开后的题库保留、MathJax、PDF.js 真 Worker、本地 Tesseract 英文 `TEST` OCR、无未捕获脚本错误或 CSP 违例。英文 Canvas OCR 不代表中文扫描 PDF 全流程、大文件或真实 AI/WebDAV 服务已验证。5 项共享 TODO 属于既有双端迁移缺口，详见[阶段 A 记录](../../../test/dual-platform/README.md)。

本地诊断记录：`apps/desktop/.reports/mist-blue-tests.log`、`mist-blue-desktop.log`；截图为 `mist-blue-home-{default,minimum,wide}.png`、对应的 `import`、`practice`、`exam` 及导航状态图片。这些生成文件不提交。仅修改桌面样式、资源准备、验证脚本和说明，未修改共享 Web 业务、Rust 权限、存储格式、依赖锁文件，未提交或推送。
