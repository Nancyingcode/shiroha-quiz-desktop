# JavaScript 可读性规则与练习题号解析实施计划

## 建立基线

- 在现有 ESLint 文件发现入口增加只读报告，按文件统计四类命中。报告用新增规则单独检查，沿用现有解析方式和排除范围。记录基线提交、文件数、各类命中和练习模块的命中。
- 先写边界样例，再接入项目规则。复用 Stylistic 检查其支持的语句与类方法间距，补齐函数表达式、对象方法和注释归属。长块诊断用于审查，函数说明、正则说明和空行作为可执行的格式检查。

## 修改练习模块

- 先用现有实现验证一项合法、一项越界的题号输入仍整组失败。提取单个题号片段识别与范围校验，保留主函数的去重、排序和报错。
- 为练习模块补齐函数与正则说明以及空行。再次运行报告。长块按职责评审，整文件通过后接入试点门禁。

## 验证

- 执行规则样例、练习回归、桌面 typecheck、全量 lint、测试和资源准备。尝试构建和桌面测试，记录实际结果。
- 在风格指南中说明试点范围、报告命令和复查标准。记录试点前后的数据与长块评审结果。

## 基线和试点结果

按试点最终的规则扫描提交 `b508251` 中的 167 份手写 JavaScript。空行一项汇总语句、类成员和对象方法三种诊断。长块按语法块计数，外层和内层块可以分别命中。

| 诊断 | 仓库基线 | 练习模块改前 | 练习模块改后 |
| --- | ---: | ---: | ---: |
| 缺函数说明 | 2,417 | 9 | 0 |
| 长代码块 | 730 | 5 | 3 |
| 缺正则说明 | 1,691 | 3 | 0 |
| 缺空行 | 6,909 | 22 | 0 |

题号解析原先有 32 行函数体和 21 行内部回调，两处长块命中已清除。练习模块余下的三个命中来自浏览器脚本封装、复盘行生成及其中的字段投影回调。脚本封装提供共享接口并限制变量作用域。复盘字段的历史兼容与状态归类应在有针对性的复盘重构中一起验证，本轮只处理该部分的说明与间距。

后续从 `apps/desktop` 执行 `pnpm run lint:incremental --readability-report` 即可得到逐文件 JSON。诊断附带行列，命中本身不影响退出码，执行或解析失败返回非零。

## 验证结果

- 题号解析重构前后通过 9 项练习回归。另对照 6,301 组输入，两版的索引和错误文案一致。
- `pnpm run typecheck`、`pnpm run lint` 和 `pnpm test` 通过。整套测试 774 项通过，1 项因 Windows 临时目录不区分大小写而跳过。
- 桌面 Release 构建和隔离测试版构建通过。WebView2 冒烟覆盖区间题量限制、单个起点跨库出题以及本轮错题页的题号。测试版打包的训练脚本与工作树版本一致。

## 第二批实施

- 选择 `platform/index.js`、`study-sessions.js` 和 `ai-prompts.js`。三个模块的诊断总数分别为 6、22 和 17，已有平台装配、会话资源释放和 AI 导入回归可直接验证。
- 分别抽取浏览器存储装配、练习资源释放和 AI 提示词构造的独立职责。复用原有导出、提示内容、存储键和操作顺序。重点核对桌面已注入的平台所有权、练习切换时的清理顺序以及提示词文本和图片占位处理。
- 各文件的注释、正则用途与空行诊断归零且相关测试通过后，逐个加入门禁并重跑全量检查。记录仍需审查的长块及保留原因。

| 文件 | 缺函数说明 | 缺正则说明 | 缺空行 | 长块审查项 |
| --- | ---: | ---: | ---: | ---: |
| `platform/index.js` | 1 → 0 | 0 → 0 | 4 → 0 | 1 → 1 |
| `study-sessions.js` | 5 → 0 | 0 → 0 | 15 → 0 | 2 → 2 |
| `ai-prompts.js` | 7 → 0 | 4 → 0 | 3 → 0 | 3 → 2 |

浏览器入口将存储适配器、数据键和缓存失效监听归到同一函数，外层负责识别已注入的桌面平台和发布浏览器接口。练习切换将资源清理提到会话工厂之外，工厂从 32 个有效代码行缩到 25 个，负责会话状态和访问器。AI 模块移出独立的导入请求构造和批量核对提示词，依赖调用方的工厂从 114 个有效代码行缩到 64 个。剩余五处长块分别来自三个文件的私有作用域和两个工厂，继续保留在报告中供审查。

三份文件启用门禁前共通过 133 项定向回归。AI 请求及图片占位等输出逐项与基线一致。启用后通过全量 lint、typecheck 和整套测试，776 项测试通过，1 项因 Windows 临时目录不区分大小写而跳过。真实浏览器的保存、考试和 AI 导入场景 3 项通过，桌面隔离测试版构建和 WebView2 冒烟 44 项通过。三个模块的桌面打包脚本均与工作树版本一致。
