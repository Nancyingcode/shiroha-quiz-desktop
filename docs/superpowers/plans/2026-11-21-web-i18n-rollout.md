# 简中与英文界面扩展实施计划

[扩展设计](../specs/2026-11-21-web-i18n-rollout.md) · [已验收的试点](./2026-11-20-web-i18n-pilot.md) · 工作分支 `codex/web-i18n-pilot`

1. 补英文学习流程用例。接入题库管理与题目编辑、收藏和错题、考试与训练记录及复盘。用原有中英文兼容测试核对业务数据。
2. 补英文导入和备份流程用例。接入导入、预览、常见诊断、设置与备份；原有样例、状态判断和文件格式按既有方法校验。
3. 接入 AI、WebDAV 和桌面专属提示。保留本地资源加载、安全约束、原生错误码和可重试行为。
4. 运行浏览器、桌面单测和 WebView2 运行验证，执行项目配置的类型、格式、Lint 与构建检查，记录双端覆盖和实际限制。

## 交付范围

- Web 和 Windows 桌面共用简体中文和英文界面词条。语言偏好使用试点已有的本机设置，界面切换和备份恢复分别管理。
- 覆盖题库管理、收藏和错题筛选、考试、复盘、导入预览、备份及 AI 与 WebDAV 的主要操作和提示。历史模式、掌握状态、题干与答案继续按兼容格式读取和保存。英文导入预览同时提供原始解析报告的展开入口。
- Windows 文件对话框的应用自定义标题使用界面语言，系统控件使用 Windows 的显示语言。应用按原生错误码展示已知错误的译文。

## 验收范围

- Edge 回归使用自建题库、旧备份样本和模拟 AI、WebDAV 服务，验证中英文操作与数据往返。
- 离线 WebView2 验收使用隔离配置，核对英语界面、SQLite 数据、作答和重启后的语言偏好。
- AI 和 WebDAV 使用模拟服务验收。题库原文、服务返回内容和原始解析报告按来源展示。

## Windows 文件对话框补验

在使用独立应用标识的 Windows 发布构建中，从设置页切换简体中文和英语。通过实际应用入口打开以下系统窗口，并在各场景取消操作。

| 操作 | 简体中文标题 | 英文标题 |
| --- | --- | --- |
| 导入题库文件 | 选择题库、文档或备份 | Open a question bank, document, or backup |
| 导出 Web 完整备份 | 保存导出文件 | Save exported file |
| 选择 Codex 程序 | 选择 Codex 0.163.0 Windows x64 程序 | Choose the Codex 0.163.0 Windows x64 executable |

Codex 文件类型分别显示为 `Codex 程序 (*.exe)` 和 `Codex executable (*.exe)`。打开、保存和取消等系统控件使用 Windows 的显示语言。

补验中修正了备份恢复方式和取消导出提示的语言显示。重建后在同一设置页来回切换语言，核对恢复选项以及保存窗口标题和取消提示。Edge 的 8 项相关用例及 531 项共享回归均通过。
