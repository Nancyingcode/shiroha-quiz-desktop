# 简中与英文界面试点实施计划

[试点设计](../specs/2026-11-20-web-i18n-pilot.md) · 基线 `c64588b` · 任务分支 `codex/web-i18n-pilot`

1. 在现有浏览器回归中先复现缺少设置入口、练习中无法切换的问题。用自建中文题库和历史练习记录覆盖语言切换、草稿、评分与持久化。
2. 实现两种语言的资源、回退与插值。扩展本机偏好入口。给 Web 与桌面共用的页面标注静态词条，并对运行时生成的首页与练习文案添加显示层映射。
3. 接入桌面资源清单和窗口标题栏。用现有 WebView2 回归验证英文启动、练习中切换、提交和离线。核对浏览器的窄屏布局和键盘操作。
4. 运行指定浏览器回归、`pnpm run typecheck`、`pnpm run lint`、`pnpm test`、`pnpm run build`、`pnpm run build:test` 和 `pnpm run test:desktop`，记录验证范围与环境限制。

## 验收结果

- 浏览器回归通过 273 项。增加结果分页翻译后，复跑了 9 项试点与分页用例，覆盖 390 像素窄屏、作答草稿、评分、恢复旧 Android 备份及语言保存失败。
- Windows WebView2 烟测通过 65 项。试点用例通过键盘切换语言，在作答中切回中文，并核对原题、SQLite 成绩和应用重启后的英文偏好。外网流量由隔离代理拒绝。
- 类型检查、Lint、桌面单测、531 项共享单测及普通和验收专用 EXE 构建通过。临时目录不区分大小写，一项相应的检查按环境跳过。
