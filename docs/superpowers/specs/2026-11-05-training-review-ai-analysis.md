# 训练复盘中的 AI 解析设计

日期：2026-11-05。用户已确认采用与错题本一致的界面和交互。

## 范围与交互

训练记录、首页最近训练和训练结果共用的复盘页，在当前题目没有解析时复用错题本的解析组件。配置了 AI 时显示「暂无解析」「AI 生成解析」和本题数据发送范围；未配置时提供前往 AI 设置的入口。生成中、停止、生成失败、待保存草稿、重新生成、放弃及保存反馈均沿用错题本现有行为，不自动发送请求或保存草稿。有解析时继续展示原有解析，不新增覆盖入口。

生成使用当前历史题目快照和当时作答，发送范围沿用单题 AI 的既有实现。图片未发送、答案可能不一致或信息不足时保留人工核对提示。用户确认保存后只写入明确来源题库中的对应题目解析；来源缺失、题目变化、读取或保存失败时保留草稿并提示，不更改历史快照、成绩或答案。保存期间若来源已有不同解析，继续使用现有覆盖确认。

快照中的解析优先于来源题库的当前解析；快照无解析时按明确的来源题库和题目补读。来源未知或已删除时，不把当前题库中同 ID 的题目冒充来源。旧记录缺少完整快照时保留既有缺失说明，AI 仅使用记录实际保存的信息。

## 状态与边界

- 每个复盘条目以记录、条目索引、来源题库和题目 ID 标识会话，避免跨库或同一记录内重复题目互相串联。
- 切题、筛选导致选题改变或离开复盘时，及时终止并释放该条目的请求和草稿；迟到响应不得更新新选题。仅重绘当前选题时保留其会话。
- 不改变存储格式、IPC、原生权限或 AI 服务配置；桌面继续先按需读取来源题目，再复用既有保存事务和网络边界。
- 训练复盘原有的筛选、答题卡、导航、焦点和历史只读行为保持不变；只有用户主动确认保存解析才修改来源题库。

## 验证

先以真实浏览器与隔离 mock 编写回归，覆盖无解析的正确、错误及未作答题，生成、保存、历史不变、重开读取、未配置、来源缺失与切题或离开后的迟到响应。复用现有错题解析测试检查停止、重试和存储回滚，并补充受影响的原生惰性读取场景。按仓库规范执行 Web 回归、桌面测试、类型检查、lint、构建和适用的 WebView2 验证；不调用真实 AI 服务或使用真实用户数据。
