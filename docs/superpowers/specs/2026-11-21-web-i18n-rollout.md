# 简中与英文界面扩展设计

从已通过验收的[界面试点](./2026-11-20-web-i18n-pilot.md)继续。Web 和 Windows 桌面共用词条，各页沿用本机语言偏好。

## 学习界面

- 顶层页面、筛选、分页、对话框和状态提示使用当前语言。作品标题、题库和分组名称、题干、作答、解析及历史快照按原文展示。
- 题型、学习模式和错题掌握状态在显示时查询译名。控件值、评分、历史记录和备份继续使用现有格式。日期和数字只在展示时格式化。
- 静态节点和动态控件继续使用试点的词条标记。动态表格和弹窗沿用原有查询与事件处理，语言切换不得发起业务写入、重算成绩或弃用输入草稿。

## 导入、网络及桌面

- 导入选项、进度、预览及常见诊断接入词条。解析的判断值、分段关键词和历史草稿保留原义。界面翻译由显示侧完成，已有和无法识别的诊断保留供人工核对。
- AI 和 WebDAV 本地化设置、任务状态、确认和失败反馈。请求正文、生成结果、认证、备份和服务协议按原有契约处理。
- 文件窗口使用当前语言的应用自定义标题，系统按钮遵循 Windows 语言。原生错误按已有错误码显示安全的译文。

## 验收

- 中文与英文都使用同一份题库和历史备份完成查题、考试、错题复习及复盘。核对分数、选项、题库、记录和筛选的兼容值。
- 用自建中文题库验证英文界面下的导入诊断和入库结果。AI 与 WebDAV 验收使用模拟服务。Windows 测试使用隔离数据目录，在断网 WebView2 环境覆盖语言切换与启动。
