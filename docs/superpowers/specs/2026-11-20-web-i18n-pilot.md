# 简中与英文界面试点设计

用户已确认先实施评估中的试点流程。Web 与 Windows 桌面版共用语言资源。

## 用户流程

- 新用户默认使用简体中文。在设置页选择“简体中文”或“English”，重新打开时沿用选择。本机偏好与侧栏折叠状态使用同一存储入口。保存失败时保留当前语言并提示重试。
- 语言试点覆盖公共导航、首页、练习设置、作答反馈及本轮结果。设置页注明试点范围。题库管理、导入、考试、独立训练复盘、AI 与备份工具按现有中文界面提供。
- 练习页也提供语言选择器。协助用户在专注模式及总提交过程中切换语言，保留当前题目、草稿、计时状态、焦点和已显示的结果。

## 文案与数据

- 语言资源随应用打包。按稳定键获取译文，使用命名参数插值，日期、数量、百分比及复数使用 `Intl`。静态 DOM 与动态练习文案以词条标识更新，保留控件和用户输入节点。富文本和题库内容仍由原有渲染函数处理。
- 本机偏好存储仅保存受支持的语言标识，与备份、SQLite 题库及学习记录独立。练习记录的 `mode: '练习'`、错题状态和导入诊断继续使用兼容值。已有题库名称、题干、选项、答案、解析保留原文。
- 桌面生成器将语言脚本作为本地资源复制，沿用现有 CSP。标题栏可访问名称使用同一资源。原生文件窗口、IPC、OCR、题库解析和 AI 输出语言属于后续工作。

## 验收

- 两端均可在设置切到英文，从首页开始练习，在轮次中切换并恢复到英文，完成提交后查看结果。用中文题库核对题目、答案、正确率、记录和历史状态。
- 检查语言选择的持久化、无效偏好回退、保存失败、键盘可达与焦点保留。验证窄屏和桌面离线资源，并用现有备份兼容回归核对原数据。
