# 导入预览本地草稿设计

日期：2026-11-17。用户已要求按上一轮功能规划分批实施；本批复用现有导入预览，不扩展题库和备份契约。

## 目标与范围

用户在识别预览中手动保存一份本机草稿，重新打开相同 Web 来源或 Windows 桌面应用后可主动恢复，继续核对，再由用户确认新建或追加题库。草稿保存题目对象及图片、识别提示与诊断、AI 尚未采纳的建议、选择和筛选、题库名称/分组/导入方式、输入文本及识别选项；可在题目行保存并记住位置，或由预览区入口尽力记录当前可见题目。文件本身和 OCR 运行状态不保存，恢复后可重新选择文件；打开的题目编辑弹窗需先保存或关闭。题库二次编辑不属于本功能，避免将其当成新的导入预览。

## 持久化和数据边界

- 使用当前来源的独立 IndexedDB，单条带版本和随机修订号的记录；不更改本地题库、备份 JSON/ZIP、跨端迁移格式、凭据或原生权限。Web 的不同来源与桌面 profile 各有独立草稿，浏览器清除站点数据可能删除草稿，完整备份不包含草稿。
- IndexedDB 写事务在修订号相符时整体替换；配额、序列化、读取和事务失败保留旧记录与当前预览并提示。不同窗口在确认后发生更改时拒绝覆盖，需重新操作。用户可确认删除已保存草稿；清除全部本地数据时同时尝试清除它。
- 保存或恢复时显式确认覆盖已有草稿或当前预览；等待期间当前内容或已保存修订发生变化时停止，避免覆盖新内容。重复恢复相同内容不重复覆盖。正在进行文件读取或 AI 请求时，恢复生效前废弃各读取槽位并取消 AI 请求，迟到结果不能修改恢复内容。旧文件选择与 OCR 运行状态不继承。
- 导入成功后，仅当当前草稿内容与该保存修订一致时，按修订号删除已保存草稿；筛选、勾选和位置变化不影响判断。不匹配或删除失败时保留并提示，避免误删另一个会话或较早版本。导入失败保留草稿。跨两个存储的提交无法实现原子性；意外退出可能遗留旧草稿，恢复与最终入库仍须用户主动操作。追加目标不再存在时，必须重新选择，不能回退到当前题库。
- 恢复前验证版本和基本结构；不支持或损坏的记录保留，不自动修复或覆盖。草稿可包含用户题目和原文，使用本机存储，不上传；不要保存 API Key 或其他凭据。

## 验证

以隔离浏览器 profile 验证保存、刷新恢复图片、题目、筛选及建议，读取/AI 迟到与覆盖确认，存储失败、重复恢复和导入生命周期；保留现有导入、AI 与浏览器回归。运行项目 typecheck、lint 与文档检查；桌面资源生成和真实 WebView2 重启由联合验收覆盖。
