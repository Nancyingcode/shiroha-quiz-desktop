# 训练记录单条删除设计

日期：2026-11-11。用户已确认本会话生成的效果图，并明确要求按该版本实施。

## 目标与范围

- Web 和复用相同界面的 Windows 桌面端，在训练记录列表中支持删除单条练习或考试记录。
- 保留现有筛选、分页、导出、清空和复盘入口；不新增批量删除或撤销功能。
- 只删除选中的训练记录及其中的作答和复盘快照。题库、错题本、收藏、其他训练记录和已有备份不随之删除。
- 首页最近训练、记录总数和依赖训练记录的统计在保存成功后按剩余记录刷新。

## 界面与交互

- 每条记录的“查看复盘”旁增加红色描边的“删除”按钮，窄屏允许换行；按钮的可访问名称包含记录标识信息。
- 点击后显示现有居中模态确认框，标题为“删除训练记录？”，展示训练名称、题库和时间，并说明删除后无法查看该次复盘，题库、错题本和收藏不会被删除。确认按钮为红色“删除记录”，另有“取消”和关闭按钮。
- 默认聚焦取消；Tab 保留在弹窗内，Escape 和关闭按钮等同取消。取消不写入数据并恢复焦点。成功删除后将焦点移至记录筛选控件，并提示删除成功。
- 根据当前筛选和分页重新显示列表；删除最后一页的最后一条时沿用现有分页边界，切回仍有内容的页。

## 数据与失败处理

- 按记录 ID 定位，并在确认后进入现有独占保存事务，再次核对目标。若 ID 缺失、重复或确认期间目标信息发生变化，停止删除并提示，避免误删其他记录。
- Web 沿用现有浏览器快照保存；桌面复用已有 `delete_record` 和记录顺序变更，不必加载未展开的记录正文，不新增 IPC、权限或数据格式。
- 明确未提交时沿用事务回滚和重试提示，记录及其他用户数据均保留，不能显示删除成功。若桌面提交回包和持久回执都无法读取，则沿用现有“结果暂时无法确认”提示，重新启动后核对，不把结果未知宣称为已删除或已保留。
- 恢复点或先前导出的备份可以包含已删除的记录，恢复备份仍遵循现有行为；本功能不修改备份内容或自动同步远端。

使用隔离题库和虚构训练记录覆盖取消、确认、重复 ID、安全文本、保存失败及重试、列表分页与首页统计；桌面验证惰性摘要下删除及重载持久化。另验证对话框键盘焦点、窄屏布局及现有对话框默认样式。
