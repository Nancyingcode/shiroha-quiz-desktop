# 当前题库预览：单题选项、长题干查看与复制设计

日期：2026-10-27。状态：用户已确认并授权实施；实现及验证记录见[实施计划](../plans/2026-10-27-bank-question-preview.md)。

## 1. 目标与现状

在“当前题库预览”中直接核对单题选项、阅读完整长题干并复制题干，不必进入练习或题库编辑。

现有 [页面](../../../apps/web/index.html) 使用八列表格，包含选择、序号、题型、题干、答案、分类、分值和操作；[renderBankPreview](../../../apps/web/app.js) 将题干截断至 80 字，操作区只有删除。选项已有 `options` 数组，包含 `key` 和 `text`。桌面通过 `nativePage` 分页，并在绘制当前页前调用 `loadNativeItems` 加载题目正文。

## 2. 推荐交互：行内展开

在操作列的“删除”前统一增加次要按钮“查看详情”。点击后在对应题目下一行插入跨八列的详情区域，按钮变为“收起”。保留原表格字段、答案列、批量选择和删除入口。此次文案替代初版图中的“查看选项”，让长题干查看也有明确入口。

选择行内展开，是因为核对选项需要保持题号、题干和上下相邻题目的位置关系；弹窗会增加关闭操作，独立选项列则容易使现有八列表格过宽。

每次仅展开一道题；打开另一题时收起上一题。点击题干、选项或行内空白不触发勾选，只有原复选框改变批量选择。首次进入默认全部收起，不增加“展开全部”。

### 展开后的内容顺序

1. “完整题干”标题与右侧“复制题干”按钮，下方显示完整题干，包含已有题图、公式和表格。
2. “选项”标题，选项逐条纵向排列，标签与正文分开对齐；长文本自然换行，不截断。
3. “已存答案：B”一类文字，复用适用于该题型的既有答案格式化逻辑；缺失时显示“未提供答案”。

选项为只读内容，不使用可作答的单选框或复选框。能与已存答案明确匹配的选项显示轻量背景和“已存答案”文字标记；多选标记所有匹配项。标记仅表达题库中已有答案，不代表系统已验证其正确性，不推断或补写答案。

示意（内容为演示）：

```text
选择  #   题型  题干                  答案  …  操作
□     12  单选  下列哪项属于……        B     …  收起  删除
      ┌──────────────────────────────────────────┐
      │ 完整题干                    [复制题干]    │
      │ 下列哪项属于……？                         │
      │ 选项                                     │
      │ A  第一项内容                            │
      │ B  第二项内容                 [已存答案] │
      │ C  较长的第三项内容，自动换行……           │
      │ D  第四项内容                            │
      │ 已存答案：B                              │
      └──────────────────────────────────────────┘
□     13  多选  ……                    AC    …  查看详情  删除
```

## 3. 题型和异常处理

| 场景 | 展示行为 |
| --- | --- |
| 单选、多选及兼容多选题型 | 按原始顺序显示所有选项，不重排、不重新编号 |
| 选择题没有选项 | 显示“该题暂无选项，请检查题库内容”，保留完整题干与已存答案 |
| 判断题 | 有选项则原样展示；没有则显示“该判断题未提供独立选项”，不虚构选项 |
| 填空、简答 | 使用“查看详情”，显示完整题干、已有选项（如有）及参考答案，无选项时说明“该题型无需选项” |
| 空选项、重复标签或答案不匹配 | 保留原始内容；空正文显示“选项内容为空”，不修改数据；无法明确匹配的答案仅文字展示 |
| 图片或公式 | 复用现有富内容渲染与媒体访问边界；图片失败提供可理解的占位文本 |
| 加载失败 | 显示“题目加载失败，请重试”，允许重试；不得把未加载误报为没有选项 |

本期不增加编辑、答题、AI 补全或解析展开功能。

### 3.1 超长题干阅读

- 列表继续保留紧凑摘要；从安全的可读文本生成摘要，不把 HTML 标签、图片数据或富文本标记直接截断展示。文字实际被截断时，在省略号后显示独立的“查看全文”文字按钮。图片型题干提供“含图片”提示，完整内容仍从“查看详情”进入。
- “查看全文”和“查看详情”打开同一个详情区，不叠加弹窗。前者只执行打开，已展开时定位到完整题干标题；后者负责展开或收起。普通题干文字保持可选择，不把整个单元格变为按钮。
- 展开后正文完整渲染，保留段落与换行，不限制字数、不再次省略。使用页面滚动，不增加题干内部的纵向滚动条；长词自动换行，宽表格可局部横向滚动。
- 题干工具栏在详情范围内随页面滚动保持可达，提供“复制题干”和“收起详情”；位置避开应用固定顶部栏。收起后恢复到原题目操作按钮与所在行，避免长正文收起后丢失阅读位置。
- “查看全文”将键盘焦点移到完整题干标题，便于继续阅读；普通“查看详情”切换仍保留按钮焦点。减少动态效果，不强制平滑滚动。

### 3.2 复制内容与反馈

- 一键复制完整题干的可读纯文本，不复制列表省略摘要，不额外附加题号、选项、答案、解析和操作按钮。原题干自身包含的题号或材料文字原样保留。用户也可拖选局部文本进行系统复制。
- 普通文本保留原有段落、换行和标点；富文本去掉展示标签，解码实体；表格按行换行、单元格用制表符分隔；公式保留已有的可复制公式源文本，不抓取渲染器重复的辅助节点，不进行语义改写。
- 图片在文本中的对应位置使用“[图片：已有描述]”，无描述时使用“[图片]”；附属题图放在题干文字之后，不重复输出已内嵌的同一图片。不把 Base64、本地路径或内部媒体 URL 写入剪贴板，不做 OCR。包含图片时按钮旁提示“复制文字，图片以占位说明保留”；纯图片题目同样明确只能复制占位说明。
- 用户点击后才调用剪贴板接口。复制成功显示“已复制完整题干”，含图片时明确“已复制题干文字（图片为占位说明）”；按钮短暂显示“已复制”，随后恢复。不读取剪贴板、不修改题目或学习状态。
- 空题干且无题图时显示“暂无题干”，禁用复制。加载尚未成功时禁用复制，不能复制旧题内容。
- 自动复制被拒绝时，在当前详情区展开带可访问标签的只读纯文本框，内容与一键复制完全一致；提示“自动复制失败，请选中文本后按 Ctrl+C，或使用系统复制菜单”，提供“全选文本”和“收起手动复制区”。先聚焦并选中文本，保证失败后确实存在可手动复制的内容，不伪报成功。
- 项目已有 `copyTextV23` 使用 `navigator.clipboard.writeText`，但失败时只提示、没有返回成功状态。实施时复用其平台方式，局部提供可判断结果与手动复制区的处理，不为本功能改变其他复制入口行为，不新增原生剪贴板权限或依赖。
- 复制时捕获当前题库 ID、题目 ID 与完整文本。异步完成后仅更新仍对应该题的反馈区域，切换题目或翻页后不得把旧题“已复制”状态显示到新题上。

## 4. 状态、性能与实现边界

- 展开状态只属于当前预览页面，以题库 ID 和题目 ID 定位，不使用行号；不写入存储、备份、练习或考试状态。
- 翻页、切换题库或离开题库页面时收起；当前题被删除或题库内容替换时清除展开状态。勾选和清空批量选择不影响展开。
- 复用当前页已加载的题目正文；仅为展开题目生成富内容 DOM，不加载整个题库，也不为此新增 IPC、数据库字段或依赖。
- 异步回调沿用现有版本校验思路，同时检查题库、题目、页码和展开请求是否仍有效，避免切换后旧结果覆盖新内容。若无需额外加载，不引入多余加载状态。
- 复用 `renderQuestionBodyV83`、`renderQuestionContent` 等已有渲染入口，但接入时核对选项图片和不可信内容处理，不直接拼接原始 HTML。
- 实现主要涉及 `apps/web/app.js`、`apps/web/styles.css`，按需调整 `apps/web/index.html`。桌面资源通过既有流程生成，不手改 `dist`。本期不包含 Android 原生界面或历史 Web assets 同步。

## 5. 视觉与无障碍

沿用现有卡片、次要按钮、边框与圆角风格，展开区使用低对比底色和适当内边距。选项单列排列；窄屏不新增表格列，沿用现有横向滚动容器，图片宽度不得撑破详情区。

按钮使用原生 `button`，提供带题号的可访问名称、`aria-expanded` 和 `aria-controls`；展开内容关联该按钮。键盘 Enter/Space 可切换，焦点留在触发按钮，屏幕阅读顺序为原题目行后接详情。状态更新使用适量的实时反馈；如重绘移除了焦点节点，将焦点恢复到对应按钮，题目已删除则移至合理的相邻操作。无需焦点陷阱。默认不增加展开动画。

## 6. 验收与后续实施

确认设计后再编写实施计划，并先补回归用例：

- 单选、多选能查看完整选项和已存答案；同一按钮可收起，打开另一题只保留一个展开区。
- 长文本、图片、公式、空选项、缺失答案、不匹配答案、判断与非选择题按上述规则呈现，不改变题目数据。
- 单题查看与勾选、全选本页、清空选择、删除及跨页选择互不串联；切换题库、翻页与删除后不出现陈旧详情。
- 桌面延迟加载和失败重试不展示其他题目内容，查看不会触发持久化写入或整库正文加载。
- 键盘操作、焦点保留、可访问名称、窄屏和桌面 WebView2 显示通过验证。
- 长题干摘要与完整阅读内容对应；“查看全文”定位正确，长正文不二次截断；收起后原行及焦点可见。
- 复制万字题干不截断；段落、实体、表格、公式和图片占位符合规则，不混入选项、答案、按钮、内部路径或重复的公式文本。
- 剪贴板允许、拒绝、空内容、纯图片、快速切换题目等场景均有准确反馈；手动复制区内容与一键复制内容一致，且可用键盘操作。

实现阶段执行相关 Web 回归，以及桌面 npm test、typecheck、lint、build；通过隔离的 build:test 与 test:desktop 验证桌面资源加载，未自动覆盖的视觉场景补人工验收。设计文档阶段仅执行文档检查。
