# 清透蓝白居中弹框

用户已在本会话预览三种方案并选择「清透蓝白」，授权实施。

## 范围与交互

- 将共享 Web 业务的原生 alert、confirm、prompt 替换为同一居中组件，桌面通过现有资源生成流程复用。
- 白色面板、浅蓝图标底、20px 圆角、背景遮罩；标题、正文、右侧按钮遵循已选预览。退出练习明确显示「继续练习」「保存并退出」。其他场景保留原业务说明。
- 使用浏览器原生 dialog 顶层模态能力，无新增依赖、远程资源或权限；消息仅作为文本显示。
- 确认和输入返回 Promise，调用方必须等待结果；取消返回 false 或 null，提示框关闭后继续。保留原有数据和评分规则。
- 确认框初始焦点在取消按钮，输入框聚焦并选中默认值；Tab 限制在框内，Esc 和关闭按钮执行取消，背景点击不执行确认；关闭恢复触发控件焦点。
- 页面只显示一个弹框，其余请求排队；保存锁允许弹框内部交互，背景保持锁定；弹框内按键不得触发练习快捷键。
- 小屏仍居中，超长内容可滚动，遵循减少动画偏好。

## 边界

浏览器关闭标签页的 beforeunload 提示由浏览器管理，无法可靠改为异步自定义框，保留其数据保护作用。操作系统文件选择框、第三方库内部提示及已有业务编辑面板不在替换范围。

## 验收

覆盖确认/取消/输入默认值与空值、Esc、焦点恢复与循环、队列、文本安全、事务中确认、练习退出及原生窗口关闭检查。运行桌面单元测试、类型、lint、Web 页面回归、AI 回归、桌面构建及隔离 WebView2 smoke。
