# 错题解析展示设计

日期：2026-10-29。状态：已按用户批准的图示实施并验证，结果见[实施计划](../plans/2026-10-29-wrong-question-analysis-display.md)。

## 需求与范围

错题本及答题后的错题均展示题目解析；没有解析时，明确显示「暂无解析」，并提供「AI 生成解析」。生成内容先作为草稿展示，用户核对后可保存到来源题库解析。用户已明确批准该流程，并授权按图示实现。

本版面向 Web 与复用 Web 资源的桌面界面，包含错题本、逐题作答后答错反馈、总提交后的本轮错题一览，以及考试结果中的错题。Android 原生界面不在本次共享 Web 实现范围内。

## 现状

- 共享业务位于 `apps/web/app.js`，样式位于 `apps/web/styles.css`。
- 错题本 `renderWrongBook`、本轮错题 `renderPracticeWrongRows`、练习反馈及考试结果在解析为空时会省略解析区域。
- 错题本读取当前题库的题目；本轮错题优先读取作答明细中的 `nativeQuestion` 快照。快照已有解析时沿用快照；缺少解析时允许补读来源题库中已保存的解析，历史快照和持久化格式不变。
- 已有全部选项展示和正确答案、当时错误答案的对照，保留现有行为。
- 逐题练习已有 AI 解析的配置、受控请求、草稿、人工核对及保存逻辑，新增入口应复用这些能力。

## 展示规则

1. 解析固定放在答案对照下方，默认完整展开。
2. 有解析时显示「解析」标题和完整正文，复用现有题目内容渲染，保留换行、公式及已有支持的富文本。
3. 解析不存在、为空字符串或只有空白字符时，保留「解析」标题，正文显示「暂无解析」。
4. 有解析使用浅蓝底色；空解析使用浅灰蓝底色和辅助文字色。标题与正文均提供明确文本，状态不只依赖颜色。
5. 逐题作答后答错反馈、错题本、本轮错题一览及考试结果中的错题采用一致的解析区域。
6. AI 生成仅在用户主动点击后请求，不自动生成；未保存内容明确标为「AI 解析草稿」「草稿 · 未保存」。已有解析正常展示，新增入口不主动替换已有解析。
7. 正确题的既有反馈、题目判分、自评、错题记录、收藏及掌握状态保持现有逻辑；示意中的控件只用于本地预览。

## 界面示意

一版蓝白界面，保留「错题本」「答错后反馈」「本轮错题一览」三个场景切换。在原有空态旁增加 AI 生成按钮，支持本地模拟点击生成、停止、重新生成、放弃草稿、保存及保存成功的反馈；另可切换生成失败和未配置 AI 的状态。示意使用自建示例题及预置示例解析，不发送请求，不读取真实凭据或用户题库。预览位于当前会话的可视化目录，不进入应用资源或构建产物。

考试错题使用同一解析区块的视觉与空态规则，不另建一种布局。

## AI 生成与保存流程

| 状态 | 展示和操作 |
| --- | --- |
| 暂无解析 | 「暂无解析」和「AI 生成解析」；简要说明仅发送本题题干、选项、答案及作答 |
| 未配置 AI | 保留空态，提示尚未配置并提供「前往 AI 设置」，沿用已有设置页 |
| 生成中 | 「正在生成 AI 解析…」和「停止生成」，同题不重复请求；重新生成时保留已有草稿 |
| 草稿待保存 | 明确标注 AI 草稿、未保存、AI 参考答案和与题库答案的核对结果；提供「保存到题库解析」「重新生成」「放弃草稿」 |
| 保存中 | 禁用重复保存与重新生成；保留草稿正文 |
| 已保存 | 当前页面展示保存后的解析，并提示「已保存到题库解析」；题库和错题本后续可使用该解析 |
| 生成或保存失败 | 展示可理解的错误和重试入口；已有题库内容与草稿保留，保存失败回滚本地修改 |

保存写入来源题库的题目解析，不改变题干、选项、标准答案、评分或历史作答记录。当前结果页在成功保存后立即展示新解析，不重写历史记录中的题目快照。

AI 对答案有疑问、与题库答案不一致或仅发送了文字而未发送图片时，沿用已有人工核对提示。未发送题目图片，不扩大现有数据上传范围；题库其他内容和整轮作答记录不随该请求上传。API Key 和其他凭据不进入题目消息、日志或备份，身份认证沿用已有通道。

复用现有 AI 执行方式、超时和取消、错误脱敏、安全渲染、存储事务及原生网络边界。请求绑定来源题库与题目；切页、换题或来源题目变化时不把过期结果显示到其他题。保存前重新核对来源和题目指纹；来源题目不存在时提示无法保存并保留草稿；期间已产生其他解析时沿用覆盖确认，不静默覆盖。草稿使用现有会话内生命周期，不增加持久化格式。

## 批准后的验证要求

- 先补充能够复现解析缺失时不展示空态的回归，再实施局部修复。
- 覆盖正常解析、缺失解析、空字符串及纯空白文本；覆盖错题本、逐题反馈、错题一览和考试错题结果。
- 用 mock 验证 AI 配置缺失、主动生成、停止、重试、草稿、保存成功与失败；检查请求数据范围以及草稿不会自动写入题库。
- 验证跨场景查看已保存解析、来源题目缺失或变化、覆盖确认、过期请求隔离，以及保存不影响判分和历史记录。
- 验证多行文本、公式、富文本及不可信内容继续由现有安全渲染逻辑处理。
- 保留全部选项及答案对照的既有回归。
- 按根规范完成共享 Web 和桌面适用的测试、类型检查、lint、资源生成、构建及运行验证；执行前核对现有脚本和隔离测试环境。
