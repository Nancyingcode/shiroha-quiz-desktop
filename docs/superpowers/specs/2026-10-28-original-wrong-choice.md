# 错题原作答标记设计

用户于 2026-10-28 批准本会话示例图，允许按图实施。

## 行为与范围

- Web 与桌面共用错题本、练习结束错题一览的全部选项展示。
- 正确选项为绿色；当时选错的选项为红色边框、浅红背景、红色文字和红底白字的字母圆标，文字标记为“✕ 当时选择”。其余选项保持中性样式。
- 正确选项同时被选择时显示“✓ 正确答案 · 当时选择”；多选漏选的正确项仍为绿色，不能误标成红色。
- 下方对照区显示“正确答案”和“当时错误答案”。旧错题没有保存选择时显示“未记录”；本轮明确未作答时显示“未作答”。
- 复用现有 `lastAnswer` 保存最近一次错误作答，练习（单题与总提交）和考试采用相同规则，后续正确复习不覆盖它。再次答错时更新为该次错误作答，与现有最近错误时间对应。
- 不新增持久化字段、IPC 或迁移；不从当前勾选项或不完整历史记录推测旧错误答案。保持跨题库同 ID 隔离，不修改评分、正确答案、错题计数或原有备份格式。
- 单题答后、考试结果继续使用现有选项标记，采用一致的红绿文字和圆标。

## 验收

覆盖单选、多选、判断、未作答、未知旧记录、跨库同 ID、保存后重载，以及答对后保留旧错选；验证 Web、桌面和备份往返。窄屏、图片选项、长文本应完整显示，颜色同时有文字说明。
