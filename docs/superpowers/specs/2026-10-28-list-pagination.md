## 1. 目标与现状

按用户提供的分页参考图统一列表分页：左右箭头、可点击页码、省略号、蓝色描边的当前页，以及每页条数下拉框。“错题一览”和“当前题库预览”均可完整翻页查看。

[共享 Web 业务](../../../apps/web/app.js) 中的 `nativePage` 目前固定每页 50 条，仅提供上一页、下一页与页数文字。当前题库预览已在 Web 和桌面启用；题库列表、错题本、收藏、记录只在桌面延迟加载模式下分页。[练习完成后的错题一览](../../../apps/web/app.js) 当前一次渲染全部错题。

## 2. 覆盖范围

Web 与桌面使用相同交互，覆盖以下六处：

| 位置 | 调整 |
| --- | --- |
| 题库列表 | 统一分页控件，并启用浏览器分页 |
| 当前题库预览 | 替换现有固定 50 条分页，保留详情与批量管理 |
| 错题本 | 统一分页控件，并启用浏览器分页 |
| 收藏 | 统一分页控件，并启用浏览器分页 |
| 记录列表 | 对现有筛选结果分页，保留“最近若干条／全部”的范围选择 |
| 总提交练习完成后的“错题一览” | 新增分页，覆盖本轮全部错题 |

本期不调整答题中的上一题／下一题、考试题目导航、记录内既有明细摘要、导入预览或 Android 原生界面，不同步 Android 历史 Web assets。

## 3. 分页外观与交互

- 默认每页 10 条，提供 `10 条/页`、`20 条/页`、`50 条/页`、`100 条/页` 四档；各列表独立保存当前会话中的条数选择，不写入用户存储或备份。
- 分页位于对应列表下方。当前题库预览的分页放在表格横向滚动区域之外，避免需要横向滚动才能操作。
- 常规状态接近参考图：`‹  1  2  [3]  4  5  …  50  ›   [10 条/页 ▾]`。普通页码为轻量文字按钮，当前页蓝字、蓝色细边框与小圆角；箭头与条数选择保持相同高度。
- 总页数较少时显示全部页码；较多时保留首页、末页和当前页附近的连续页码，省略中间范围。省略号为不可点击文本，不新增跳转规则或输入框。
- 点击页码直接跳转，箭头每次翻一页；首页禁用向前箭头，末页禁用向后箭头。少量文字显示当前范围与总条数，避免用户把当前页数量误认为总量。
- 修改每页条数、切换题库或更改筛选／排序后回到第一页；同一列表普通重绘保留当前页。删除、移出或标记掌握导致总页数缩小时，自动退到最后一个有效页。
- 非空单页仍显示页码与条数选择；空列表只显示现有空态与零条提示，隐藏无效的分页按钮。
- 翻页后让对应列表顶部可见，不滚到整个页面开头。键盘焦点恢复到新分页中相应控件；原页码不再显示时落到当前页按钮。条数切换后焦点仍在下拉框。
- 窄屏减少相邻页码数量，并允许总数与条数选择换行；保留当前页、首末页和箭头，不让分页撑出卡片。

## 4. 列表状态与数据边界

### 当前题库预览

- 保留全题库连续序号，不在每页重新从 1 编号。
- “全选本页”仅选择当前页，跨页已选项继续保留，选择总数和删除范围仍覆盖所有已选项。
- 翻页或修改每页条数时收起题目详情；旧复制反馈不能更新到新页。
- 桌面继续仅加载当前页正文，使用现有渲染版本校验，快速翻页时旧响应不能覆盖新页；失败保留重试入口。

### 错题一览

- 标题计数、完成统计与保存记录仍覆盖本轮全部题目，分页仅控制当前显示哪些错题。
- 保留原始答题题号、来源题库、全部选项、正确答案、当时错误答案、解析和未作答语义，不重新评分或改变历史记录。
- 每次完成新一轮练习时从第一页开始；全对时保留原“本轮没有错题，全部答对了”提示，不生成分页。
- 翻页只重绘本轮错题内容与分页，保留成绩卡片、返回设置和再练一次入口；不新增持久化写入。

### 其他列表

- 先按现有规则筛选和排序，再计算分页；筛选计数、批量操作及完整导出不能只针对当前页。
- 收藏列表使用连续序号；启动收藏练习仍针对既有完整范围。题库列表分页不改变题库分组、选库或导出选择的语义。
- 分页状态只属于页面会话；替换数据、恢复或重置后清理不适用的旧页码。复用既有按需读取与迟到响应校验，不新增 IPC、数据库字段、依赖或存储迁移。

## 5. 实现与无障碍

在既有分页函数上收敛页码计算和控件渲染，复用到错题一览；保持现有 JavaScript 风格，不引入框架。主要文件为 [app.js](../../../apps/web/app.js)、[styles.css](../../../apps/web/styles.css)，按需小幅调整 [index.html](../../../apps/web/index.html)。桌面资源由既有生成流程维护。

使用具备独立可访问名称的 `nav`、原生 `button` 和 `select`；箭头提供“上一页”“下一页”标签，页码提供“第 N 页”名称，当前页设置 `aria-current="page"`。禁用态、焦点边框和当前页不只依赖颜色表达；总数与页码变化使用适量状态反馈。保持键盘 Enter／Space 与原生下拉框操作，不增加动画。
