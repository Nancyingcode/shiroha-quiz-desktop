# 已导入题库单题与批量删除设计

日期：2026-10-24。状态：用户已确认，已实施并通过 Web 与隔离桌面验证。执行结果见[实施计划](../plans/2026-10-24-bank-question-deletion.md)。

## 目标与范围

Web 与桌面共用的题库管理页面支持直接删除已导入的试题，包括单题删除和批量删除。本次不修改 Android 原生界面或历史 Web assets，不新增依赖、存储格式或特权 IPC。

## 现有实现

- `apps/web/app.js` 的 `renderBankPreview` 只展示试题，Web 限制为前 300 题，桌面采用摘要与分页按需加载。
- “更多 → 编辑 / 移动分组”通过 `editBankByIdV45` 进入导入预览，已有单题删除与批量删除，随后通过 `saveBankEditSessionV45` 保存；当前禁止保存空题库。
- `runMutation`、`saveSilent` 提供统一保存与失败回滚。新操作应复用这些机制，保留桌面未加载题目的数据。

## 交互方案

1. 题库管理的当前题库试题列表增加选择框和每行“删除”按钮，列表上方增加“全选本页”“清空选择”“删除选中试题”及已选数量。
2. Web 列表补充分页以覆盖第 300 题之后的内容；桌面复用现有分页。选择以题库 ID 与试题 ID 标识，在同一题库翻页时保留，切换题库或重新导入、覆盖题库后清空。全选本页只影响当前页，不隐式选择其他页。
3. 单题与批量删除均二次确认，显示题库名称、删除数量，并说明对应错题和收藏会移除、历史成绩会保留、不能直接撤销。取消不修改任何数据。
4. 允许删除全部试题，保留题库名称、分组和 ID，显示空题库提示；删除末页全部试题后回到有效页。
5. 保存期间禁用重复操作，成功后更新题数、统计和相关列表；失败保留原题库与选择，显示可重试错误，不显示成功提示。
6. 保留原二次编辑入口，统一其删除后的关联清理规则，并允许保存删空后的既有题库；首次导入仍不接受空题库。

## 数据与会话规则

- 仅删除目标题库中明确选中的试题，保留剩余试题的 ID、原题号、内容与顺序；界面序号可以连续显示，不改写题目本身。
- 同一次保存清理被删除试题的错题、收藏及跨端收藏元数据；不影响其他题库中的同名或相同 ID 试题。
- 保留已完成的练习和考试记录及其历史快照，不重算历史成绩，不物理清理可能被历史记录或其他题目引用的媒体文件。
- 若目标题目仍处于进行中的练习或考试，阻止删除并提示先结束相关会话，避免改变正在作答的题目集合、计时和评分。其他题库或未被会话使用的试题可以正常删除。
- 桌面删除前确保目标数据完整可用，不能将分页中的未加载内容当作空数据保存。沿用现有事务与恢复机制，不新增独立数据库写入路径。
- 原二次编辑保存也须检查实际删除的 ID 集合，适用相同会话约束和关联清理，避免绕过规则。
