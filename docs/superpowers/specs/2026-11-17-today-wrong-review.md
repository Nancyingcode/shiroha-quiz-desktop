# 今日错题复习设计

## 目标和入口

首页“待复习错题”显示当前练习范围内今天应复习及已逾期的未掌握错题数，并作为键盘可操作的按钮直接开始练习。范围沿用现有单题库或分组设置；分组内不同题库的同 ID 题目分别计算。错题本原有“重练未掌握错题”入口及其选择方式保持不变。

## 队列规则

- 只计算题库中仍存在、状态不是“已掌握”的题目。同一题库的同一题目只出现一次；历史孤立错题保留原数据但不进入练习队列。
- “今天”按设备当前本地日历计算，到下一本地日零点为止，不按固定 24 小时推算日界线。今天任意时刻到期的题目均计入，下一日零点及之后到期的不计入。
- 没有 `nextReviewAt` 的历史错题视作尚未安排，加入队列；无法解析的日期同样可复习，避免历史数据被永久排除。
- 先按到期时间排列已逾期题目，再排列未安排的历史错题，最后按时间排列今天到期的题目；同一时间保持题库原始顺序。
- 首页数量和本轮选题复用同一计算规则。打开练习时重新计算，避免首页显示后跨日或数据发生变化而使用过期队列。

## 交互、状态与平台

无待复习题时按钮不可用；有题时直接开始按队列顺序、单题提交的练习，题量为全部。若已有未完成练习，先确认替换，取消时保留原会话。复习轮次不写入普通顺序练习的继续进度；作答与掌握状态沿用现有错题更新和保存逻辑。

数量随保存后的作答、错题管理、题库及范围变更刷新；停留首页跨过本地午夜时自动刷新，页面恢复可见时重新核对时间。桌面端使用现有题库摘要中的 ID 计算数量，开始时沿用按需加载与现有读取失败保护，不为统计加载全部正文。无需新增存储字段、备份格式或原生权限。

## 验证

覆盖跨日边界、未来、已掌握、缺失或错误日期、已删除题目、跨库同 ID、排序、旧字符串记录、状态和范围更新、键盘入口、未完成会话保护，以及桌面摘要和按需读取。运行相关 Web 回归与项目适用的测试、类型检查、lint、构建和桌面运行验证；环境限制如实记录。
