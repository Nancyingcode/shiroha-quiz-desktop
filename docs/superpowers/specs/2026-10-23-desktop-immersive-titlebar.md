# 桌面沉浸式标题栏设计

日期：2026-10-23

状态：用户已确认按视觉预览实施，并明确导航栏不再显示图标和应用名；本设计及限定窗口权限已获实施授权。

## 1. 呈现与交互

- 移除独立的 Windows 原生标题条，在桌面页面顶部提供 36px 高的自定义标题栏。
- 标题栏与正文使用同一雾蓝背景坐标，不增加分割线、浮卡、模糊或独立阴影。滚动时标题栏固定且不会透出正文。
- 左侧显示小图标和 `Shiroha Quiz`，右侧保留最小化、最大化/还原、关闭三个按钮，每个宽 46px。
- 图标和应用名仅在顶部标题栏出现；左侧导航移除原品牌区及副标题，菜单上移，从「首页」开始排列。
- 按钮默认透明，普通悬停使用浅蓝色，关闭悬停使用红色；提供中文可访问名称、键盘焦点与工具提示。
- 空白标题区域支持拖动，双击最大化/还原；按钮不触发拖动。最大化状态通过窗口实际状态更新图标和名称。
- 正文、菜单和专注模式为标题栏预留高度，最小窗口下不遮住导航、题干、提交、退出或弹窗操作。
- 保留边缘缩放、最小窗口限制、系统关闭行为与现有数据保存规则。Windows 原生最大化按钮的悬停贴靠面板不作为自定义按钮的等价承诺；验证系统快捷键贴靠及拖动体验。

## 2. 实现与权限边界

现有 `tauri.conf.json` 保留原生装饰，`withGlobalTauri` 为 `false`，主窗口能力的 `permissions` 为空。安装的配置 schema 明确 `titleBarStyle` 仅用于 macOS，不能直接用于当前 Windows 工程。

采用 Tauri 官方自定义标题栏路径：`decorations: false`，本地页面调用受能力限制的窗口 API。启用 `withGlobalTauri`，直接使用随 Tauri 提供的 API，不增加 npm 生产依赖或第三方窗口插件。

能力仅匹配本地 `main` 窗口，逐项授予下列权限，不启用 `core:default` 或 `core:window:default`：

| 权限 | 用途 |
| --- | --- |
| `core:window:allow-start-dragging` | 用户在标题空白区域拖动当前窗口 |
| `core:window:allow-minimize` | 最小化按钮 |
| `core:window:allow-toggle-maximize` | 最大化/还原按钮与标题双击 |
| `core:window:allow-is-maximized` | 同步实际最大化状态 |
| `core:window:allow-close` | 关闭按钮，沿用正常窗口关闭流程 |

拖动与双击由本地脚本显式处理，避免默认拖动标记隐式依赖其他权限。控制按钮不接受任意窗口标签或外部操作参数，仅通过当前窗口对象调用 Tauri 内置命令；原生侧继续由 Tauri 能力系统校验。窗口变化后读取最大化状态，不引入通用事件监听权限。

不增加原生文件、网络、shell、进程启动或凭据权限，不开放远程来源能力。CSP、应用标识、存储来源与数据格式不变。

## 3. 文件范围

- `apps/desktop/frontend/`：标题栏模板、本地控制脚本与样式，沿用 JavaScript/JSDoc 和既有类型检查，不引入框架。
- `apps/desktop/scripts/prepare-web.mjs`：校验并复制标题栏资源，仅在生成页面注入；失败前保全旧输出，不修改共享 Web 源码。
- `apps/desktop/src-tauri/tauri.conf.json`：原生装饰与限定窗口权限。
- `apps/desktop/test/`：资源生成、能力白名单与窗口行为的回归测试。
- `apps/desktop/scripts/smoke.mjs`：实际窗口状态、操作、布局与隔离进程关闭验证。
- 桌面说明及实施计划：记录运行方式、验证结果和平台边界。

## 4. 验证

先添加失败回归，再实现接入与行为。验证样式和脚本来自本地、权限严格等于白名单、资源生成幂等且非法输入不破坏输出。

运行 `npm test`、`npm run typecheck`、`npm run lint`、`npm run build` 和 `npm run test:desktop`。若实现确需修改 Rust，则先阅读 Rust 指南并追加格式、Clippy 与单元测试。

实际 WebView2 验证覆盖 900×640、1280×860、1600×1000、最大化和还原；分别检查首页、导入、练习、考试、临时展开导航和弹窗。验证窗口拖动、双击、最小化、最大化、还原、关闭，以及关闭重开后的隔离题库保留。测试只操作测试脚本启动的进程，不关闭用户正在使用的 dev 窗口。
