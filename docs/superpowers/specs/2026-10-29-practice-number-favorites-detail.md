# 刷题题库题号与收藏夹详情设计

日期：2026-10-29。用户已批准本会话中的交互图例，授权按本设计实施，无需重复审批。

## 目标与范围

- 刷题显示与题库一览一致的题号，收藏夹以表格和行内详情展示完整选项。
- 修改共享 Web 界面，桌面通过现有资源生成流程复用；不修改 Android、持久化格式、IPC、安全权限或依赖清单。
- 保留现有提交、评分、收藏、分页与单题练习流程，不增加批量删除题库或编辑入口。

## 刷题题号

题干上方显示“题库第 N 题”、题型及所属题库名称／分类。本轮进度独立标明“本轮进度 · 第 X / Y 题”，答题卡继续使用本轮序号。

N 取题目在所属题库当前列表中从 1 开始的位置，与题库一览相同，不使用导入文件的 `number` 字段或收藏列表顺序。按题库 ID 和题目 ID 定位，覆盖随机、筛选、自选范围、单题收藏、分组跨库及两个库中相同题目 ID 的情况；无法定位时明确显示“题库题号未知”，不编造题号。单题提交与总提交共用该规则，考试编号保持现有语义。

## 收藏夹

- 沿用题库一览的表格风格，列为题号、题型、题目摘要、答案、分类、分值、操作；题号为所属题库题号，保持现有收藏顺序与分页。
- 保留“练习收藏题”“清空收藏”“练习本题”“取消收藏”。查看／收起详情只改变界面，不产生存储写入。
- “查看详情”在当前行下方展开完整题干、所有已有选项、已存答案与已有解析；明确标注能唯一匹配的答案选项，不补造答案。非选择题、空选项、缺失答案、图片与公式复用题库详情的处理。
- 复用既有详情渲染、复制全文与复制失败后的手动复制功能。每次只打开一道题；默认列表收起，图例展开首题仅用于演示详情。
- 翻页、重绘、切库和离页时移除详情及其监听；旧异步复制结果不能污染新详情。加载失败显示重试入口，不将失败展示为无收藏。
- 分页继续处于表格横向滚动容器之外。窄屏允许表格局部横向滚动，详情和工具栏宽度限制在可视容器内。

## 验收

浏览器回归覆盖两种提交模式、跨库相同 ID、收藏单练、完整选项与解析、只读查看、键盘收起与焦点恢复、分页与切库关闭、加载失败重试、窄屏。通过自建题库和隔离 profile 验证桌面 WebView2 实际显示与操作，不使用真实用户数据或真实收费服务。
