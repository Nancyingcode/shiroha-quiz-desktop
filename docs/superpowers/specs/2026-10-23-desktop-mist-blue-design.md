# 桌面端「雾蓝一体」视觉设计

日期：2026-10-23

状态：用户从三版桌面视觉预览中明确选择「雾蓝一体」，本文件记录该方向的实施范围。视觉选择已有授权，不重复确认。

## 1. 目标与范围

背景、左侧菜单和右侧内容共用连续的浅灰蓝画布，消除独立浮动侧栏、厚重白卡和多重阴影造成的割裂。仅升级 Windows 桌面呈现，沿用共享 Web 业务与现有功能。

- 背景以低对比雾蓝光晕衔接导航与主区域；导航自身无外框、实色底或阴影。
- 首页欢迎区、统计和学习建议直接依托背景排版，使用留白和细线建立层次。
- 保留现有题库选择、保存、四个快捷入口、题量与学习统计、数据备份提示及版本信息。
- 题干、表单、表格和弹窗保留稳定的浅色阅读面，避免把所有控件透明化。
- 主操作使用克制的蓝色实底；普通操作、输入和选中导航统一圆角、文字与边界颜色。
- 使用系统字体和既有角色素材；不新增远程资源、字体、生产依赖或动画。

## 2. 布局与交互

桌面默认窗口 1280×860、最小窗口 900×640，并检查宽屏。菜单与正文共享布局，正文在可用区域内居中；取消原来以整个视口为基准的固定安全留白。侧栏收起时保留普通页面的内容位置，避免反复切换导致内容跳动。

刷题与考试继续沿用现有专注模式、导航展开/收起、题号与统计侧栏及其状态流转。预览中的简化答题页仅用于展示阅读材质，不引入新的练习流程。现有题目编辑、AI 解析、考试评分、导入导出与持久化规则均不变。

导航展开、弹窗与正文具有必要的层级；专注模式的临时导航使用稳定底色，避免与题目文字重叠。键盘焦点始终可见；正确、错误、警告状态保留原有语义色和文本。减少动态效果时不使用动画。

## 3. 实现边界

在 `apps/desktop/frontend/` 增加桌面专用样式，由已有资源准备脚本复制至生成目录，并在共享样式之后加载。通过桌面根标识限制样式作用域；不手工编辑 `dist`，不修改 Web/Android 样式，不复制业务页面或脚本。

现有 Web 样式存在多轮 `!important` 覆盖，桌面适配只对必要的既有选择器做集中覆盖，不删除历史注释或重构共享样式。生成器在清理输出前验证新增输入，拒绝链接及不完整入口；失败时保留既有输出。CSP、原生权限、应用标识和存储来源不变。

## 4. 验收

1. 桌面生成入口正确加载本地样式，Web 源文件保持不变；重复生成一致，非法输入不破坏既有输出。
2. 首页导航无独立白色浮框，主体与背景连贯，统计与按钮可读。
3. 默认、最小及宽屏尺寸下不出现页面级横向溢出、导航覆盖正文或不可达操作。
4. 首页快捷入口、导入、题库、练习、考试、错题、收藏、记录与设置可正常打开；专注模式可进入与退出。
5. 运行桌面 test、typecheck、lint、build 和实际 WebView2 smoke。浏览器视觉检查不能替代 WebView2 验证。
