# 当前题库搜索设计

## 目标和交互

在“当前题库预览”中提供关键词和题型筛选。关键词匹配题干或选项的文字，不区分英文大小写；首尾空白不参与匹配。题型与关键词同时生效，多选的历史别名按既有规范化逻辑归一。空关键词表示不限制文本，空结果明确提示；完全没有题目时保留原空库提示。

筛选在整个当前题库应用，再按既有列表分页；序号仍是题目在原题库中的序号。每次更改关键词或题型从第一页开始，同一筛选翻页、展开和收起既有详情时保留关键词、页码和位置。切换题库后保留筛选条件并重新查询新库，选择项按既有规则清空。筛选不会修改题库、导出或练习数据；已有跨页选择不会因筛选而丢失，批量删除仍作用于明确选中的题目。

输入框和题型选择器使用原生可键盘访问的表单控件，搜索状态及空结果通过状态文本反馈。详情继续使用原有展开、收起和焦点恢复逻辑，不另建详情页。

## 正文读取与竞争

桌面题库摘要只包含 ID 和题型，关键词搜索前必须读到正文。按题型预筛后使用既有受控读取接口分批补读该题库的候选题；仅题型筛选不需要额外补读全文。读取进行中显示状态并禁用批量操作；失败保留筛选条件并允许重试，不能把未读题目误判为无结果。常规无关键词预览仍只读取本页，筛选结束后沿用现有内存释放生命周期，不改变存储或 IPC 契约。

每次查询关联当前题库、筛选条件、页面所有权和渲染版本。输入、切库、切页、离页或重绘导致旧请求失效；每批结束先检查所有权，过期读取不更新列表或显示旧错误。数据写入沿用现有读取与事务协调。

## 验证

浏览器交互覆盖分页外题干和选项、富文本、题型叠加、大小写、空结果、详情关闭后页码及焦点、切库、筛选中的选择行为。以桌面摘要模拟验证分批补读、晚到结果和失败重试；最后按项目要求执行相关测试与桌面资源验证。
