# WebDAV 云备份使用指南

适用范围：Web 与 Windows 桌面，入口均为“设置与导出 → WebDAV 云备份”。旧 Android 的配置、自动备份及清理规则已[归档](../archive/android-era-documents/WebDAV云备份使用指南/Shiroha Quiz WebDAV 云备份使用指南.md)，当前不再维护安卓自动备份。

## 配置与请求边界

填写服务商提供的 WebDAV 根地址、远端目录、用户名与密码，保存配置后测试连接。建议使用 HTTPS 和应用专用密码。

Web 由浏览器请求，接受完整 HTTP/HTTPS 地址，受证书、跨域与混合内容检查约束。HTTPS 页面访问 HTTP 服务可能被浏览器拦截；网络失败不能只归因于混合内容。CORS 需要允许应用来源、OPTIONS/PROPFIND/MKCOL/GET/PUT 方法及 Authorization、Content-Type、Depth 请求头。

Windows 使用受控原生 WebDAV 请求，保持证书校验和逐跳重定向限制。配置与记住的凭据绑定，不能通过关闭校验解决网络错误；具体约束见[桌面说明](../../apps/desktop/README.md)。

## 密码保存

- Web 默认仅保留在当前标签页会话；勾选记住才保存到本浏览器独立凭据存储，可通过清除配置删除。
- Windows 未记住的密码只在进程内存，记住时使用 Windows 凭据管理器。
- 密码、AI Key、MinerU Token 不进入题库或云备份。恢复和跨设备迁移后按提示重新配置，不手工复制凭据文件。

## 手动上传与恢复

1. 先保存题库和学习数据，再点击“上传当前完整备份”。当前功能按用户操作上传，不是后台同步。
2. 点击“刷新远程备份”查看列表，按当前界面选择下载或恢复。
3. 恢复前核对来源、完整性和内容。合并导入保留当前数据并追加题库；覆盖恢复替换本机数据，先保留设备外备份。
4. 核对题库、图片、错题、收藏与记录。Windows 的恢复点和失败保全说明见桌面文档；不要把旧安卓“保留三组安全备份”等规则套用到当前端。

Web/Windows 不自动删除远端旧文件，不提供旧安卓的按日/周、充电/Wi-Fi 调度。远程备份保留多久由用户管理；本机恢复点不能代替设备外备份。

## 常见问题

| 现象 | 检查 |
| --- | --- |
| 网络或 CORS 失败 | 服务地址、证书、浏览器限制、服务端 CORS 与连接诊断 |
| 401 | 用户名、应用专用密码、账号权限 |
| 404/405 | 根地址、远端目录、WebDAV 方法与反向代理配置 |
| 上传过大 | 服务端容量限制及备份图片体积 |
| 恢复不符合预期 | 来源文件、合并/覆盖选择、题目与图片核对结果 |

诊断资料先脱敏；不粘贴密码或专有题库。旧 Android JSON/ZIP 仍按现有能力导入，迁移见[停止维护说明](../universal/Android停止维护与迁移.md)。桌面与浏览器本机数据不会自动共享。
