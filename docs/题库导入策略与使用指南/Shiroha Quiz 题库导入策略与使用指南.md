# 题库导入策略与使用指南

适用范围：Web 与 Windows 桌面。旧 Android 操作及原生专属批处理规则保存在[历史指南](../archive/android-era-documents/题库导入策略与使用指南/Shiroha Quiz 题库导入策略与使用指南.md)，当前不再提供安卓构建或维护入口。

## 选择入口

1. 普通 DOCX、XLSX/CSV、TXT、文字层 PDF、题库 JSON 或粘贴文字，在“导入题库”选择文件或输入文本。
2. 题目和答案分开时，使用双文件导入，核对题号匹配及分区。
3. 旧应用备份 JSON/ZIP 优先使用“设置与导出 → 备份与恢复 → 导入备份 JSON/ZIP”，明确选择合并或覆盖。普通题库 JSON 不包含完整学习数据，不能当作完整备份。
4. 扫描 PDF 先使用 OCR 测试区取得文字或 DOCX，人工核对后导入。桌面内置离线 PDF/中英文 OCR 资源；Web 运行条件与扩展资源以实际环境为准。

## 核对后再保存

先在识别预览中核对题目数量、题号、题型、选项、答案、解析、多空及图片。缺答案时保留缺失状态，不凭常识补写；AI 草稿仍需人工确认。

识别不准时优先整理题号、选项分行和答案标记，参照[标准格式示例](../标准题库格式示例/标准题库格式示例.md)。复杂材料和集中答案区不要仅依据历史安卓回归判断成功。

AI 可辅助整理、核对或补解析；使用外部服务会发送所需题目内容。不要把真实密钥放入题库，测试使用自建材料和 mock。Windows 的 Harness 与直接 API 配置见[桌面说明](../../apps/desktop/README.md)。

## 保存、备份与迁移

导入后先试做几题并检查错题、收藏和学习记录。重要数据导出 Web 完整 JSON；含图片题可另导出“含图片备份 ZIP”。两种载荷不同，保留原始文件。

覆盖恢复前确认影响范围，合并导入保留当前数据并追加备份内容。Web 数据按访问来源隔离；桌面使用独立本地数据库。应用不自动读取浏览器或 Android 私有数据。

旧安卓迁移与兼容限制见[停止维护与迁移说明](../universal/Android停止维护与迁移.md)，文件范围见[格式支持说明](../题库导入格式支持说明/Shiroha_Quiz_题库导入格式支持说明.md)。
