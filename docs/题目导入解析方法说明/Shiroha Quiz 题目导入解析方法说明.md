# 题目导入解析方法说明

当前维护范围为 Web 与 Windows 桌面，两端复用共享 JavaScript 业务。原文主要记载历史 Android 解析器规则，已[完整归档](../archive/android-era-documents/题目导入解析方法说明/Shiroha Quiz 题目导入解析方法说明.md)；本页说明当前使用与核对边界。

## 处理流程

文件或粘贴文本先转为可识别内容，再识别题号、题干、选项、答案、解析与题型。双文件导入另将答案与题目匹配。最终进入预览，由用户核对并确认导入。

文本建议使用独立题号、分行选项和明确“答案：”“解析：”标记。多空答案需保留每空及可接受答案的结构；主观题文本不应被手工改造成选项。示例见[标准题库格式](../标准题库格式示例/标准题库格式示例.md)。

复杂材料、共用题干、集中答案区、解析中的编号、缩写选项、紧凑答案及重复题号都可能引起误识别。预览重点检查题数、答案覆盖和对应关系；不以题数正确代替答案正确，也不把 AI 结果当作原始答案。

## 当前与历史回归

当前自动回归位于[test/dual-platform](../../test/dual-platform/README.md)，包括格式、导入、题目业务和 ZIP 安全等断言。旧 Kotlin 解析样例保存在[历史样例目录](../../test/fixtures/legacy-android-parser/README.md)，69 个旧预期不是当前 Web 的通过清单，不存在可运行的当前 Kotlin Runner。

本次停止安卓维护没有移植其材料题、图片绑定或其他原生专属策略，也没有改变现有 Web 解析规则。发现当前行为问题时，使用脱敏样例先增加可复现回归，再局部修复。

## 备份不是重新解析原题

完整 JSON/ZIP 恢复使用现有格式识别、版本校验与数据转换，保留现行支持的旧 Android 备份字段。它与从 Word/PDF/TXT 重新识别题目不同；不要通过重新解析绕过未知版本、路径安全或凭据校验。

兼容范围和步骤见[旧安卓备份迁移](../universal/Android停止维护与迁移.md)。
